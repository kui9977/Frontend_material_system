# Frontend_material_system
大创项目金属材料分析系统前端部分，负责人曹岩


这个前端项目是一个基于 HTML、CSS 和 JavaScript 的单页面应用，结合了 Spring Boot 后端服务，主要用于项目管理和数据分析。以下是项目的主要功能和结构介绍：

### **功能概述**
1. **新建项目**：
   - 用户可以通过表单输入项目的详细信息（如项目名称、颜色、密度等）并提交到后端进行分析。
   - 提交后，后端返回分析结果。

2. **项目管理**：
   - 显示所有已创建的项目列表，包括项目名称、创建时间等。
   - 支持批量管理功能（全选、删除）。
   - 用户可以查看单个项目的详细信息和分析结果。

3. **数据可视化**：
   - 提供项目数据的可视化功能，用户可以选择项目并生成图像。

4. **设置**：
   - 包括个人资料、账户安全、功能反馈、权限说明和退出登录等功能。

5. **搜索功能**：
   - 用户可以通过搜索框快速查找项目。

### **技术栈**
- **HTML**: 用于页面结构设计。
- **CSS**: 使用 `base.css` 和 `content.css` 定义了页面的样式，包括侧边栏、表单、按钮等。
- **JavaScript**: 
  - 使用原生 JavaScript 和 `axios` 库与后端进行交互。
  - 实现了动态渲染、事件监听、表单提交、数据管理等功能。
- **后端支持**: 通过 Spring Boot 提供 RESTful API，处理前端的请求。

### **文件结构**
- `index.html`: 主页面，包含导航栏、表单和主要内容区域。
- `base.css` 和 `content.css`: 定义了全局样式和页面布局。
- `main.js`: 实现了页面的动态交互逻辑，如切换内容、表单提交、数据渲染等。
- `login.js`: 实现了登录和注册功能。

### **交互流程**
1. 用户通过导航栏选择功能（新建项目、项目管理等）。
2. 页面根据用户选择动态切换内容区域。
3. 用户提交表单或执行操作时，前端通过 `axios` 向后端发送请求。
4. 后端返回数据后，前端动态更新页面内容。

### **页面设计**
- **侧边栏**: 提供功能导航，支持选中状态切换。
- **顶部栏**: 包含搜索框和用户信息。
- **主要内容区域**: 根据功能显示不同的内容（如表单、项目列表、可视化图表等）。

这个项目适合用于管理和分析与材料相关的项目数据，具有良好的用户体验和交互设计。
